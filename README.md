# 🛠️ Playwright + Cucumber Automation Framework

This repository contains an automation framework using **Playwright** and **Cucumber** with the **Page Object Model (POM)** for testing [Automation Exercise](https://automationexercise.com/). 🚀

---

## 📌 Prerequisites

Before running the tests, ensure you have the following installed:

- **Node.js** (v16 or later) 👉 [Download Here](https://nodejs.org/)
- **Git** 👉 [Download Here](https://git-scm.com/)
- **Chrome / Edge / Firefox** (Browsers for Playwright tests)
